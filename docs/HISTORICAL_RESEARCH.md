# Historical research

Versions through `0.12.0rc2` contained synthetic endurance experiments and an experimental metric-based succession calibrator.

Those materials remain available in Git history and prior release artifacts for reproducibility. They are not used by the current benchmark, and the current package does not treat the earlier coherence measurements as validated predictors of agent quality or as a basis for promotion.

The maintained path now compares observed outcomes directly under a fixed task, constraints, budget, evaluation policy, and checker identity.
